# Словарь замен «мёртвое → живое»

Дословные примеры правок из книги. Не подставляй механически: замена
выбирается по смыслу, окраске, характеру говорящего, эпохе.

## Содержание

1. Канцелярские фразы
2. Чувства и состояния
3. Деепричастия, причастия, пассив
4. Словесная алгебра: факт, момент, шанс, вещь, фигура
5. Иностранщина
6. Живая речь (диалог)
7. Внутренний монолог

## 1. Канцелярские фразы

| Мёртвое | Живое |
|---|---|
| поставь в известность меня или маму | скажи мне или маме |
| мы ведём борьбу за повышение успеваемости | мы стараемся хорошо учиться |
| мы провели большую работу по сбору макулатуры | мы собрали много макулатуры |
| большую помощь мы оказываем детской площадке | мы помогаем |
| мы приняли решение прекратить попытки | мы решили больше не пытаться |
| принимают активное участие в борьбе за повышение производительности | повышают производительность труда |
| такие замены не способствуют пониманию вас собеседниками | такие замены не помогают собеседникам вас понять |
| население, проживающее | жители района |
| встреча продолжает работу | встреча продолжается |
| произведено столько-то награждений | наградили столько-то человек |
| зверь совершил нападение | зверь напал |
| «Викинг» начал преследование | пустился преследовать, кинулся вдогонку |
| первое погружение принесло разочарование | первое погружение нас разочаровало |
| пока не прекратят его поиски | пока его не перестанут разыскивать |
| это не может не явиться плодотворным поводом для размышлений | тут есть о чём задуматься |
| нет возможности составить догадку о нашем местоположении | мы не знаем, где находимся |
| выслушайте моё предложение | вот что я предлагаю |
| это не способствовало искоренению недуга | не помогало искоренить |
| мы воздержались от заявления о дне старта | мы не сообщали о дне старта |
| по мере приближения момента встречи с нею | чем меньше времени оставалось до встречи с нею |
| по сведениям, поступавшим из разных источников | как рассказывали мне разные люди |
| в соответствии со своим характером | в согласии с... |
| переделать максимум дел в минимальное количество времени | успеть как можно больше в самый короткий срок |
| закончил объяснение задач нашего эксперимента | объяснил, для чего нужен наш опыт |
| причиной моего отказа было то, что это время было зарезервировано | я отказал, потому что на это время назначена другая консультация |
| тщательно взвесив все обстоятельства, я решила освободить тебя от твоих обязательств | я всё обдумала и решила вернуть тебе твоё слово |

| Мёртвое | Живое |
|---|---|
| мысли, порождённые состоянием разлуки | тоска |
| он находился в состоянии полного упадка сил | он совсем ослабел, лишился последних сил |
| впал в состояние прострации | оцепенел |
| я почувствовал сильное ощущение одиночества | мне стало очень одиноко |
| он почувствовал страх | ему стало страшно; он испугался, струсил, струхнул |
| он испытал сильное головокружение | у него закружилась голова |
| даже к собственной дочери он испытывал недоверие | даже собственной дочери он не доверял |
| никакой жалости к ней он не испытывал | он нисколько её не жалел |
| воспоминание было нежелательно | не хотелось вспоминать |
| мысль произвела на меня слишком ошеломляющее впечатление | слишком меня ошеломила |
| в глазах было выражение такой беззащитной доверчивости | смотрел так беспомощно, так доверчиво |
| в лице её появилось какое-то неуловимое просвежение | лицо её просветлело |
| в состоянии неудовлетворённого возмездия | его сжигает жажда мщения |
| он вдруг опять загорелся оптимизмом | он снова воспрянул духом |
| он на всё смотрит слишком пессимистически | всё видит сквозь чёрные очки |
| он ощутил глубокую депрессию | он совсем пал духом |
| охватило чувство какой-то экзальтации | самозабвенный восторг |
| они впали в панику | их охватил ужас; насмерть перепугались |
| она так нервничала | волновалась, тревожилась, не находила себе места |
| его нервы не выдержали | ему изменило самообладание, не хватило выдержки |
| потерял контроль | потерял голову; утратил власть над собой |
| она начала анализировать ситуацию | стала думать, что произошло |
| передо мной встаёт проблема | передо мной трудная задача |
| ситуация развивалась по инерции (о любви) | (полная замена живым оборотом) |

## 3. Деепричастия, причастия, пассив

| Мёртвое | Живое |
|---|---|
| он куда-то убежал, вернувшись только к вечеру | он куда-то убежал — и вернулся только к вечеру |
| покинув свой письменный стол, он отправился исследовать подвалы, не обнаружив там ничего зловещего | отправился обследовать подвалы, но не обнаружил там ничего |
| он видел себя вдвоём на пляже наслаждающимися миром и покоем | он представлял себе, как они наслаждаются миром и покоем |
| он чувствовал себя преследуемым, совершающим поступки под воздействием роковой пружины | ему чудилось, будто его преследуют, будто он действует под нажимом пружины |
| два сумасшедших рыжеволосых врача, простукивающих грудь и восхищённо хихикающих над обнаруживаемыми ими симптомами | два рыжих врача простукивают... и хихикают, находя симптомы |
| поистине счастливым поэт может считать себя, когда он чувствует свою необходимость людям | поистине счастлив поэт, когда чувствует, что нужен людям |
| нами обнаружено | мы обнаружили |
| чёрные лодки и одежды гребцов создавали впечатление армады тьмы | лодки были чёрные и гребцы тоже в чёрном — казалось, надвигается армада тьмы |
| теперь все сомнения относительно враждебных целей визита исчезли | теперь стало ясно, что приплыли они как враги |

## 4. Словесная алгебра: факт, момент, шанс, вещь, фигура

| Мёртвое | Живое |
|---|---|
| не сам факт неудачи послужил причиной отчаяния | не сама неудача привела его в отчаяние |
| последнее было таким постыдным фактом | это было постыдно |
| констатировал тот факт, что не всё идёт гладко | видел только, что не всё идёт гладко |
| меня поразил этот факт, страшный и нежданный | меня поразило страшное и нежданное открытие |
| он мужественно признал тот факт, что друг для него потерян | признал горькую истину |
| в этот роковой момент | в эту роковую минуту |
| дождался удобного момента | улучил минуту |
| в этот самый момент раздался стук в дверь | тут в дверь постучали |
| момент выбран удивительно удачно | это вышло очень кстати |
| с того момента, как мы познакомились | с тех пор, с того дня, с того часа |
| я моментально уснул | мигом, сразу, тотчас же уснул |
| самый маленький шанс лучше, чем полное отсутствие надежды | самая малая искра надежды лучше, чем безнадёжность |
| не стоит упускать шанс | не стоит упускать случай, возможность |
| выпал шанс | посчастливилось, повезло, улыбнулось счастье |
| наконец я получил шанс рассказать | наконец мне удалось рассказать |
| у нас мало шансов на победу | едва ли мы победим |
| это был мой последний шанс | это была моя последняя надежда |
| странная вещь, до чего она меняется | странно, до чего она меняется |
| одна вещь печалила его в предчувствии конца | только одно его печалило |
| фигура женщины поместилась в карету | сама эта женщина уселась в карету |
| непременно пойди навести мать. — Да, я это сделаю | Да, конечно (непременно) |
| я это сделаю (в ответ на «возьми и храни его») | А как же! Ещё бы! |

## 6. Живая речь (диалог)

В диалоге канцелярит вдвойне безобразен. Герой не говорит протоколом.

| Мёртвое | Живое |
|---|---|
| я ценю оказываемую мне честь | я очень польщена |
| я выражаю вам благодарность | я вам очень благодарен |
| тогда я нанесу ему визит | зайду к нему |
| я должна тебе кое-что доложить | я тебе кое-что расскажу |
| я провожу рекогносцировку | хочу нащупать почву, разузнать |
| могли бы вы быть счастливы, имея мужем вот такого человека, как я? | вы уже немного знаете, что я за человек, — могли бы вы быть счастливы с таким мужем? |
| последнее слово, которое ты от меня слышишь | да, последнее, больше ты от меня ничего не услышишь |
| я не позволю, чтобы меня постоянно отодвигали на задний план | нечего меня вечно оттирать |
| вы не возражаете против того, чтобы я включил магнитофон? | я включу магнитофон — не возражаете? |
| необходимость в приобретении запонок совпала с достаточным количеством денег в моём кармане | мне понадобились приличные запонки, и я как раз был при деньгах |
| я могу поведать миру, что ты собой представляешь | всем расскажу, какой ты на самом деле |
| покажите мне, как глубоко вы можете вздохнуть | а ну-ка, вздохните поглубже |
| здесь нужно всё уничтожить | мы тут не оставим камня на камне |
| вы нам вовсе не нужны | обойдёмся без вас |
| выхода нет, так как дело наше не терпит промедления | выхода нет, дело наше спешное |
| иду незамедлительно | иду |
| мне следовало бы раздеться, я весь мокрый от пота | не догадался, надо было раздеться. Весь взмок, хоть выжми |
| я убедился, что ваша прекрасная внешность соответствует вашим душевным качествам | убедился, что душа ваша так же прекрасна, как и лицо |
| ты её идеализируешь | не такая уж она хорошая, как тебе кажется |
| я не сторонник сегрегации. Анахронизм | глупый это обычай. Это безнадёжно устарело |
| не рекомендую тебе с ним связываться | не советую |
| сходство ситуаций разительное (в минуту смертельной опасности) | как похоже! это же то самое! |

Следи за регистром эпохи и персонажа: «планировка города» в устах мальчика
XVI века, «перед лицом компетентных судей я изложу оправдывающие меня
моменты» у крестьянина XVII века — анахронизм и фальшь.

## 7. Внутренний монолог

Раздумья передаются изнутри — безлично или от первого лица, без лишних
связок и местоимений.

| Мёртвое | Живое |
|---|---|
| ему больно. Он ранен. У него болит всё. Его ноги. | Больно. Он ранен. Болит всё: рот, ноги, спина... Ноги... |
| в зале есть и белые, а они-то не являются моими друзьями | ...а они — не друзья мне |
| у меня была мечта, которая теперь уже не может быть осуществлена | у меня была мечта, теперь уж ей не сбыться |
| его мать считала, что её сыну оказывают большую честь тем, что пригласили его выступить | мать была польщена: какая честь, сына пригласили выступить! |
| к его удивлению, никто не был убит | как ни странно, убить никого не убило |
| вокруг царила полная тишина, ни один звук не нарушал её | И так тихо вокруг... поразительно тихо! |
| все молчали, не зная, что делать дальше | Постояли, поразмыслили... |
| Грянул выстрел, другой, третий. Затем ответное эхо, вдали — крик человека | Грянул выстрел, другой, третий... прокатилось эхо, кто-то вскрикнул... |
