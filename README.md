# Нора Галь — скилл для Claude

**Редактор школы Норы Галь: убирает канцелярит, лечит переводы, возвращает тексту жизнь.**

Скилл превращает Claude в редактора, работающего по методу Норы Галь — автора книги «Слово живое и мёртвое» (1972). Галь — переводчик «Маленького принца» и мастер живого русского слова. Её метод: не свод запретов, а умение слышать текст и возвращать ему человеческий голос.

---

## Что умеет скилл

### Режим 1 — Редактура русского текста

Даёте статью, доклад, письмо, прозу. Claude диагностирует и исправляет:

- **Канцелярит** — отглагольные существительные («проведение работы по сбору»), пустые глаголы («осуществлять», «производить», «являться»), цепочки родительных падежей
- **Иностранщину** там, где она лишняя — «ситуация», «момент», «факт», «шанс», «пауза», «инцидент»
- **Словесную алгебру** — расплывчатые слова вместо конкретных
- **Вывихнутые идиомы** — «нас постигла удача», «в здравом уме и трезвой памяти»
- **Тавтологии и нечаянные каламбуры** — «внутренний интерьер», «убивал время на охоте»

### Режим 2 — Проверка перевода на русский

Даёте перевод (с оригиналом или без). Claude ищет переводческие болезни:

- **Буквализмы и кальки** — «он сунул свою руку в свой карман», «мог отчётливо видеть»
- **Вывихнутые идиомы** — кальки вместо русских эквивалентов («знаю, как свои десять пальцев»)
- **Русизмы в чужом быте** — аршины, авось, кажись в переводах с английского
- **Советизмы в чужой эпохе** — зарплата, отдел кадров, не сработалась с коллективом
- **Буква вместо духа** — чужой синтаксис, притяжательные местоимения, первое словарное значение вместо точного

## Примеры работы

**Редактура:**
> **Было:** «Мы провели большую работу по сбору макулатуры»  
> **Стало:** «Мы собрали много макулатуры»  
> **Почему:** отглагольное существительное + пустой глагол «провели» — ядро канцелярита; смысл несёт глагол «собрали»

**Перевод:**
> **Было:** «Он сунул свою руку в свой карман»  
> **Стало:** «Он сунул руку в карман»  
> **Почему:** притяжательные местоимения his/her по-русски излишни — принадлежность ясна без них

**Диалог:**
> **Было:** «Вы не возражаете против того, чтобы я включил магнитофон?»  
> **Стало:** «Я включу магнитофон — не возражаете?»  
> **Почему:** живой человек говорит живо; канцелярит в диалоге вдвойне безобразен

## Как запустить

Просто напишите в Claude:

- «Проверь этот текст по Норе Галь»
- «Убери канцелярит»
- «Текст слишком казённый, оживи»
- «Проверь перевод»
- «Звучит как перевод, исправь»
- «Не по-русски»

Если режим не указан, Claude определит его сам: следы чужого синтаксиса, притяжательные местоимения, транслитерации — признаки перевода.

## Установка

### Через Claude (Cowork / Claude Code)

1. Скачайте файл [`nora-gal.skill`](./nora-gal.skill)
2. В Claude Desktop откройте **Settings → Capabilities → Skills**
3. Нажмите **Install from file** и выберите скачанный файл

### Вручную (для разработчиков)

Скопируйте папку `nora-gal/` в директорию скиллов вашей установки Claude Code:

```
~/.claude/skills/nora-gal/
```

Структура:

```
nora-gal/
├── SKILL.md                        # Основная инструкция для модели
└── references/
    ├── printsipy.md                # Принципы Галь — система координат
    ├── kantselyarit.md             # Диагностика: признаки, маркеры, вывихи
    ├── slovar-zamen.md             # Словарь «мёртвое → живое» (200+ пар)
    └── perevod.md                  # Болезни перевода и образцы мастеров
```

## Структура скилла

### `SKILL.md`

Основная инструкция. Определяет два режима работы, задаёт процедуру (читай целиком → диагностируй → правь → проверяй правку), задаёт формат ответа и жёсткие ограничения («не переписывай голос автора», «у каждой правки должно быть основание»).

### `references/printsipy.md`

14 сгруппированных принципов из «Слова живого и мёртвого» с ключевыми цитатами. Это система координат: что считать болезнью, что — точным выбором автора. Читается первым в любом режиме.

### `references/kantselyarit.md`

Диагностический чек-лист для режима 1:
- 15 признаков канцелярита
- Канцелярские глагольные обороты
- Опасные отглагольные существительные
- Конструкции «испытывал чувство…»
- Слова-паразиты (факт, момент, шанс, вещь, данный, абсолютно)
- Иностранные слова с русскими заменами
- Пассивные обороты
- Словесная алгебра
- Мнимая учёность
- Слова в неверном значении
- Вывихи устойчивых речений
- Тавтологии и нечаянные каламбуры

### `references/perevod.md`

Чек-лист для режима 2:
- Буквализм и кальки с английского/французского
- Таблица идиом с русскими эквивалентами
- Реалии: русизмы и советизмы в чужом быте
- Имена собственные и говорящие имена
- Игра слов
- Порядок слов, инверсия, ритм
- Ошибки культурного знания
- Речь персонажей и детская речь
- Образцы мастеров (Топер, Волжина, Дарузес, Калашникова, Лорие, Холмская)

### `references/slovar-zamen.md`

Более 200 пар «мёртвое → живое» из книги, разбитых по разделам:
- Канцелярские фразы
- Чувства и состояния
- Деепричастия, причастия, пассив
- Словесная алгебра
- Иностранщина
- Живая речь (диалог)
- Внутренний монолог

Словарь — не автоподстановка: замена выбирается по смыслу, окраске, характеру говорящего и эпохе.

## Чего скилл не делает

- **Не переписывает голос автора.** Нестандартное живое слово, инверсия, просторечие могут быть точным выбором. У каждой правки должно быть основание — принцип, который можно назвать.
- **Не вычищает всё подряд.** Иностранное слово, термин или реалия могут быть единственно верными.
- **Не работает с формальным оформлением.** Прописные буквы, сокращения, числа, библиография — это зона [`russian-editorial-review`](https://github.com/sportlosos/russian-editorial-review) (по справочнику Мильчина).
- **Не работает с английским текстом.** Для английского — скилл `english-style-editor` (по Странку и Уайту).

## О методе

Нора Галь (1912–1991) — переводчик с французского и английского, редактор, теоретик перевода. Переводила Экзюпери («Маленький принц»), Хемингуэя, Дос Пассоса, Флобера. Её книга «Слово живое и мёртвое» (1972, многократно переиздавалась) — самый популярный русскоязычный учебник редактуры и художественного перевода.

Центральное понятие — **канцелярит**: болезнь языка, при которой живые слова вытесняются казёнными оборотами, глаголы — существительными, конкретное — расплывчатым. Галь показала, как это убивает не только стиль, но мысль и чувство.

Школа перевода Галь — **верность духу, а не букве**: «Перевести — значит перевыразить. Передать подлинник во всей полноте можно только отходя от буквы, только средствами и по законам нашего языка».
